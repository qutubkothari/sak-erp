# Mizantra Field Sales user guide

## Representative

Open **CRM → Field Sales**. **My Day** lists the customer, site, time, purpose and current status. Tap **Start travelling**, then **Check in** at the customer. Allow a fresh location reading; if it is unavailable or outside policy, enter a genuine reason for manager review.

During the visit, open the card. Record outcome, summary and next action; optionally attach a JPG, PNG, WebP or PDF. Save work offline if the network fails. Submit the report and then check out. **Sync** shows each waiting, committed, conflicted or forbidden operation—never assume a failed item was posted.

Commercial context is read from current CRM/ERP data. A quotation/order action is revalidated by the authoritative module. A collection promise records the customer commitment but does not reduce the invoice. WhatsApp creates a draft only; use the existing governed send screen for final consent check and sending.

## Manager

Use **Plan & Route** to review deterministic recommendations and reasons. Missing coordinates are excluded explicitly. Publish only a feasible draft; revisions preserve completed/active history and the original commitment baseline.

Use **Team** for plan/completion/missed/location KPIs and **Exceptions** for evidence review. You cannot approve an exception you requested. Approved exceptions remain exceptions and are not relabelled verified GPS.

## Offline safety

Offline work is held only for the signed-in tenant/user. Keep the app open until “saved on this device” appears. Sync after reconnecting. Logging out clears that identity’s local FSM queue; do not log out with unsynchronised work unless policy requires it.

## Pilot walkthrough

For each pilot representative, assign one account/site and publish one visit. On a physical phone, complete travelling → check-in → report → check-out once online, then repeat with the network disabled and manually sync after reconnecting. The manager should verify the team metric, review one genuine location exception, confirm that a collection promise does not alter the invoice, and send one WhatsApp draft through the existing governed connector. Record the device, browser, tenant, user, visit ID and result against AT-01–AT-36 in the acceptance report.
